# DisplayBMS

Дисплей для JK BMS PB1A16S10P (інверторна серія JK-PB, 16S) на платі CYD (ESP32-2432S028R).
Дані беруться **пасивно**: прошивка слухає кадри JK `55 AA EB 90` (протокол 015) на порту дисплея BMS
і нічого не передає.

> Статус: етап 1 (каркас, збірка). Повний README з'явиться на етапі 6.

## Збірка

- VS Code + PlatformIO, `platformio/espressif32@7.1.2` (ESP-IDF 6.1.0).
- Версії компонентів зафіксовані в `dependencies.lock`.

```
pio run                 # збірка
pio run -t upload       # прошивка
pio device monitor      # лог, 115200
pio run -t menuconfig   # налаштування: меню "DisplayBMS"
```

Після зміни `sdkconfig.defaults` видаліть `sdkconfig.cyd` або виконайте `pio run -t fullclean`.

## Перший запуск: калібровка тачу

Якщо в NVS немає калібровки, після старту з'являється екран з червоним хрестиком.
Для кожного з чотирьох кутів: натисніть стилусом або нігтем точно в центр хрестика, потримайте ~0.5 с і відпустіть.
Якщо точки неузгоджені, калібровка почнеться спочатку. Результат зберігається в NVS.
Повторна калібровка: кнопка «Recalibrate touch» (стирає дані й перезавантажує плату).

## Підсвітка

- Яскравість задається слайдером і зберігається в NVS при відпусканні.
- Фоторезистор (GPIO34) зменшує яскравість у темряві до 30 % від заданої, але не нижче мінімуму з Kconfig.
- Через `DBMS_BL_DIM_TIMEOUT_S` (60 с) без дотику екран тьмяніє до `DBMS_BL_DIM_PCT` (10 %).
  Перший дотик лише будить екран, кнопка під пальцем не натискається.
- Діапазон фоторезистора (`DBMS_LDR_RAW_BRIGHT` / `DBMS_LDR_RAW_DARK`) підбирається за значенням
  «LDR raw» на тестовому екрані: на яскравому світлі і з закритим датчиком.

## Підключення до BMS (попередньо)

Використовується роз'єм дисплея BMS **P5 (A1254WF-6A)**: це **RS485**, протокол 015.
Потрібен трансивер RS485. Прошивка тільки слухає і нічого не передає.

| BMS P5 | Трансивер (SN75176 / MAX3485) | CYD |
|---|---|---|
| 1 VCC (вихід живлення дисплея) | — | через DC/DC, напругу **виміряти** |
| 2 A (за JK: «negative», −) | B (pin 7, інвертуючий) | — |
| 3 B (за JK: «positive», +) | A (pin 6, неінвертуючий) | — |
| 4 GND | GND (pin 5) | GND |
| 5 K+ / 6 K− (сигнал активації) | — | не підключати |
| — | RO (pin 1) | GPIO35, роз'єм P3 (RX) |
| — | /RE + DE (pins 2, 3) | GPIO27, роз'єм CN1 (RTS, завжди низький рівень = прийом) |
| — | DI (pin 4) | підтягнути до GND або VCC трансивера |

- У JK «A» означає мінус, а в SN75176 «A» — неінвертуючий вхід. Тому лінії перехрещуються.
  Якщо sniffer показує сміття, поміняйте A і B місцями.
- **SN75176 — 5-вольтова мікросхема.** Її вихід RO дає ~5 В, а GPIO35 витримує лише 3.3 В.
  Потрібен дільник на RO (наприклад, 1 кОм послідовно і 2 кОм на GND) або 3.3-вольтовий трансивер (MAX3485 / SP3485).
- UART0 (роз'єм Serial, GPIO1/3) зайнятий USB-UART мостом і для BMS не використовується.
  GPIO21 на роз'ємі P3 — це підсвітка дисплея.

**Живлення:** напругу на P5 VCC треба виміряти до підключення DC/DC. Якщо це напруга батареї
(до ~58 В для 16S LiFePO4), DC/DC має витримувати на вході ≥ 75 В і стояти за запобіжником.
Під час налагодження по USB з підключеним інвертором використовуйте ноутбук на батареї або USB-ізолятор.
